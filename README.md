# Training Management System (TMS)

A full-stack Training Management System for managing users, courses, enrollments, assessments, grades, certificates, learning goals, and transcripts.

The system provides role-based experiences for **Administrators, Instructors, and Students**, with a responsive green-and-white user interface.

## 🌐 Live Application

**Public URL:**

https://training-management-system-ui.onrender.com

The application is deployed using a single user-facing URL. The Angular frontend communicates with the ASP.NET Core backend through Render rewrite rules.

---

## ✨ Features

### 🔐 Authentication & Authorization

- User registration
- User login
- JWT-based authentication
- Role-based authorization
- Protected application routes
- Separate experiences for Admin, Instructor, and Student users

### 👨‍💼 Administrator

- Manage users
- Manage courses
- Access administrative dashboard
- Manage training-related information

### 👨‍🏫 Instructor

- Instructor dashboard
- Manage instructor courses
- Review student submissions
- Grade student submissions
- Track course-related activities

### 🎓 Student

- Student dashboard
- Browse available courses
- View course details
- Enroll in courses
- View grades
- Complete and view assessments
- Manage learning goals
- Access certificates
- View transcripts

### 📚 Training Management

- Course management
- Course enrollment
- Assessments
- Grade submissions
- Certificates
- Learning goals
- Training transcripts

### ⚡ Real-Time Communication

The application uses Microsoft SignalR for real-time communication.
